Huntress visar hur försvarare kan upptäcka "timeroasting" mot Active Directory

Säkerhetsföretaget Huntress publicerade den 20 november en teknisk genomgång av hur organisationer kan upptäcka så kallad timeroasting mot Active Directory – en teknik som bygger på säkerhetsforskaren Tom Tervoorts upptäckt från 2023 av hur Microsofts MS-SNTP-tillägg till tidssynkroniseringsprotokollet NTP kan missbrukas. En oautentiserad angripare kan skicka en förfalskad tidsbegäran över UDP/123 till en domänkontrollant och ange ett godtyckligt kontos relativa ID (RID), varpå kontrollanten svarar med ett kryptografiskt signerat svar som går att knäcka offline för att återställa kontots lösenordshash. Enligt forskning från Secura, som Huntress hänvisar till, går dessa SNTP-hashar att knäcka omkring tio gånger snabbare än motsvarande Kerberos TGS-REP-hashar, samtidigt som Microsoft Defender for Identity inte fångar upp den oautentiserade avsökningen. Huntress rekommenderar att organisationer loggar inkommande UDP/123-förfrågningar mot domänkontrollanter och flaggar fall där det begärda RID:et inte matchar det svarande kontot.
